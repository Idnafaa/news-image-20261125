## Run it

```sh
python3 main.py
```

That copies the front page (`entry.png`, 1024×1024, 153 KB) to `/output/entry.png`. To redraw the page from scratch, run `python3 render.py` — it draws every illustration with pure Pillow vector art, no network, no timestamps, so the output is byte-for-byte deterministic.
